= User interface

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

The library module has no user interface of its own. The repository's sample app (`app/`) is built with Android
Views: a launcher `MainActivity` with one button per estimator configuration, and one activity per estimator that
draws the estimated attitude on a 3D cube (`CubeTextureView`) together with roll, pitch and yaw text views. See
xref:sample-app.adoc[Sample app] for the purpose of each screen.
